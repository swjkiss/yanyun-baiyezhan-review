# 百业战 HUD 布局与条带标定指南

> **用途**：`scripts/make_strips.py` 的默认区域坐标依据与重新标定方法。
> HUD 小字（计时、比分、鹅血量、人墙血量杯、指挥横幅、系统播报）是复盘的**第一手客观证据**，
> 整帧送视觉模型容易误读小字，必须先用条带放大再读。

---

## 1. 坐标约定

- 所有区域用**相对分数** `[x, y, w, h]`（0~1，相对原图宽高）表示，与分辨率无关。
- 标定参考系为 **1280×720**（L1 抽帧默认输出宽度）。换算公式：
  `像素 = 相对分数 × 原图宽(高)`。
- 例：`[0.234, 0.0, 0.547, 0.056]` 在 720p 下 = 像素 `(300, 0) ~ (1000, 40)`。

## 2. 默认标定（2025-2026 赛季实测，2560×1440 源 / 1280×720 帧）

| 区域名 | box（相对） | 720p 像素 | 内容 |
| --- | --- | --- | --- |
| `top_bar` | [0.234, 0.000, 0.547, 0.056] | 300,0 → 1000,40 | 双方比分、对局倒计时钟 |
| `hud_full` | [0.234, 0.000, 0.547, 0.160] | 300,0 → 1000,115 | 顶栏 + 下方横幅区：比分/计时/**双方击杀数/在场人数/鹅血量%/人墙血量杯/指挥横幅/中场对决面板** |
| `score_ours` | [0.160, 0.000, 0.280, 0.056] | 205,0 → 565,40 | 我方分数 + 队名 |
| `score_enemy` | [0.545, 0.000, 0.280, 0.056] | 698,0 → 1057,40 | 敌方分数 + 队名 |
| `minimap` | [0.000, 0.000, 0.130, 0.244] | 0,0 → 166,176 | **左上角**小地图（据点、人墙、树、人员分布） |
| `chat_log` | [0.023, 0.755, 0.345, 0.240] | 30,544 → 471,717 | **左下角**聊天/系统播报（击杀播报、搬树提示、破塔提示） |

### `hud_full` 横幅区内的元素（从上到下）

1. 顶栏：`我方分数 队名 ｜ 对局钟 ｜ 队名 敌方分数`
2. 击杀行：`我方击杀✕数 ｜ ⚔ 30 : 30 ⚔ ｜ 敌方击杀✕数`（⚔ 两侧为双方在场人数）
3. 鹅血量行：`我方指挥横幅（如「奋力阻拦」「寸步难行」「全速进击」）｜ 敌鹅血量%（红鹅图标旁）`
4. 人墙血量杯：3 个杯状图标（亮/暗 = 血量状态）
5. 中场对决时段：整块被 1v1 面板替换（双方头像 + 回合倒计时）

## 3. 重新标定流程（版本更新 / 布局变化时）

1. 用 L1 抽 3–5 帧（开局、中期、终局各 1）：
   `extract_frames.py match.mp4 --out frames/calib --mode times --times "0:01:00,0:10:00,0:30:00" --scale 0`
2. 直接 Read 原分辨率帧，目测各 HUD 元素的像素位置，换算成相对分数。
3. 写一个区域 JSON 传给脚本：

```json
{
  "hud_full": {"box": [0.234, 0.0, 0.547, 0.16], "target_h": 300, "label": "顶栏+横幅区"}
}
```

```bash
make_strips.py --manifest frames/L1/L1_manifest.json --out strips --regions calib.json --per-page 13
```

4. Read 条带验证小字可读；不可读则增大 `target_h` 或收窄 box。
5. 验证通过后，把新坐标更新回 `make_strips.py` 的 `DEFAULT_REGIONS` 与本文件，并在报告附录记录「HUD 标定版本」。

## 4. 使用建议

- **每场复盘的标准动作**：L1 抽帧后立刻生成 `hud_full` + `chat_log` 条带（`--per-page 13`），
  一次阅读即可建立「比分-击杀-鹅血-横幅」全程时间线，再决定 L3 事件窗。
- `target_h` 经验值：读数字 150 够用；读杯/图标状态 200+；读横幅文字 300。
- 条带页高建议 ≤ 4200px（约 13 页/帧 × 300px），超出会被 Read 压缩导致小字模糊。
- 中场对决、结算画面等**全屏 UI 时段**不要用条带，直接 Read 单帧原图。
